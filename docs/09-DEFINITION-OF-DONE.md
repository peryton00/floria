# Definition of Done

- [ ] Requirement and acceptance criteria documented.
- [ ] Mobile-first responsive UI.
- [ ] Loading/empty/error states.
- [ ] Backend/domain operation works.
- [ ] Validation exists.
- [ ] Database constraints/migration correct.
- [ ] Server-side authorization tested.
- [ ] Critical failure paths tested.
- [ ] Browser verification for customer UI.
- [ ] No secrets committed.
- [ ] No hard-coded production data.
- [ ] No duplicated business logic.
- [ ] Documentation updated.
- [ ] Relevant lint/typecheck/tests pass.
- [ ] Second-person review before production merge.
