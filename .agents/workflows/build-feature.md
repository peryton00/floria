---
name: build-feature
description: Implement a Floria feature using product, architecture, design and testing rules.
---

1. Read relevant docs.
2. Inspect existing implementation and reuse components.
3. State goal, affected data, authorization, UI states and acceptance criteria.
4. Implement the smallest complete slice.
5. Add validation and server-side authorization.
6. Add tests.
7. Run lint/typecheck/tests.
8. Browser-test customer UI when possible.
9. Check secrets, duplication and client-trusted business values.
10. Report changed files, tests, browser verification and risks.
